# 回归测试

运行测试只需要 .NET 8 SDK，无 NuGet 测试框架或外部依赖：

```powershell
dotnet run --project HFSExtract.Tests -c Release
```

`Fixtures/synthetic-v4.bin` 完全由本目录的 Python 标准库脚本生成，不包含游戏数据，也不调用生产 C# 代码。JSON 文件保存已知的原始内容、SHA-256 和布局参数。若需重新生成：

```powershell
python HFSExtract.Tests/generate_fixtures.py
```

该样本的首条记录恰好占 64 字节，下一条记录占 110 字节，强制目录流使用已知计数器序列 `[0, 0, 1, 2, 3, 4, 5, 6]`。目录逻辑末尾在 1024 字节边界之前，实际缓存读取末尾在该边界之后，可同时捕获计数器重置和数据区对齐回归。

测试覆盖 ChaCha20 标准向量、任意分段、64 位计数器进位；v4 压缩、未压缩、首 1024 字节加密、flag `0x02`、空文件和空压缩文件；短读取、截断、无效计数、重复路径、错误 MD5、错误大小和不支持的 flags。损坏样本通过对已知密文进行局部改动得到，不使用生产加密实现重新生成。

`synthetic-v2.bin` 是另一个合成样本，覆盖旧格式普通、压缩和空文件，以及 v2 密文偶然匹配 v4 版本字节的探测冲突。生成器内固定的旧密码流常量最初从未修改的上游 `HFSSerpent` 获得；这些测试用于验证旧格式解析兼容，不声称独立验证旧密码算法本身。后续重新生成与测试运行均无需调用生产密码实现。
